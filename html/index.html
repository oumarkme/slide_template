Equations

Hardy-Weinberg genotype frequencies for allele frequencies $p + q = 1$:

$$p^2 + 2pq + q^2 = 1$$

Posterior probability of genotype $G$ given reads $D$:

$$\begin{aligned} P(G \mid D) &= \frac{P(D \mid G)\,P(G)}{\sum_{g} P(D \mid g)\,P(g)} \\ F_1 &= \frac{2\,\mathrm{TP}}{2\,\mathrm{TP} + \mathrm{FP} + \mathrm{FN}} \end{aligned}$$

import pysam

def count_pass(path: str, min_qual: float = 30.0) -> int:
    # Count PASS records with QUAL >= min_qual
    with pysam.VariantFile(path) as vcf:
        return sum(1 for rec in vcf if rec.qual >= min_qual)
